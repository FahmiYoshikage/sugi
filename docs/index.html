Engineering Excellence

Built from scratch with systems programming principles in pure Go.

📦

Single Binary Deployment

The backend collector, pure-Go SQLite storage, and visual web dashboard compile together into ./sugi. Just run it.

⚡

Ultra-Low Resource Footprint

Consumes under 16 MB RAM and 0.3% CPU during continuous operation. Perfect for VPS, edge nodes, and IoT.

🐧

Native Linux /proc Metrics

Parses /proc/stat, /proc/meminfo, /proc/diskstats, and /proc/net/dev directly with zero overhead.

📡

Real-Time SSE Streaming

Broadcasts live system metrics every second directly to browser dashboards via Server-Sent Events (/api/v1/stream).

📊

Zero-NPM Canvas Charts

Embedded dark-theme dashboard powered by a custom canvas charting engine. 100% offline, zero npm, zero external CDN.

💾

SQLite WAL & Online Backup

High-throughput log persistence in WAL mode (> 145k logs/sec) with automated retention pruning and zero-downtime backups.
