Engineering Excellence

Built from scratch with systems programming principles in pure Go.

Single Binary Deployment

The metric collector, Linux log harvester, SQLite storage, and web dashboard compile into ./sugi. Just run it.

Ultra-Low Resource Footprint

Consumes under 16 MB RAM and 0.3% CPU during continuous operation. Built for VPS, edge nodes, and homelabs.

Native Linux Kernel & Syslog

Parses /proc metrics directly and automatically harvests host syslog, auth.log, and journal events without external agents.

Real-Time SSE Streaming

Broadcasts live system metrics and incoming logs directly to browser dashboards every second via Server-Sent Events (/api/v1/stream).

Zero-NPM Canvas Charts

Embedded dark-theme dashboard powered by a custom canvas charting engine. 100% offline, zero npm, zero external CDN.

SQLite WAL & Online Backup

High-throughput log persistence in WAL mode (> 145k logs/sec) with automated retention pruning and zero-downtime hot backups.
